# Security and privacy

This is a local thesis demonstration, without production authentication or a backend. Demo passwords are public and do not provide a security boundary. Do not load confidential institutional or research records into a publicly hosted copy.

Do not post credentials, personal records or exploit details in a public issue. Use GitHub private vulnerability reporting if available; otherwise open a sanitized issue requesting a private contact route without including the sensitive material. Before production adoption, perform a separate dependency and application security review.
