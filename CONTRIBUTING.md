# Contributing

Small fixes, documentation improvements, synthetic regression cases and accessibility improvements are welcome. Open an issue to discuss larger changes.

1. Work in a branch, install the locked dependencies, then run `pnpm test` and `pnpm build`.
2. Explain the behavior changed and include relevant validation.
3. Use fictional data only. Never contribute student/participant records, grades, credentials, transcripts, evidence media, institutional exports or live-system screenshots.
4. Review every staged file. Ignore rules are a convenience and do not guarantee removal of private data.

Keep thesis claims separate from demonstrated application behavior. Preserve third-party license notices.
